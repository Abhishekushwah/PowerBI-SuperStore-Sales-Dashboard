# 📊 Power BI SuperStore Sales Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard developed using the SuperStore Sales dataset.

The dashboard provides insights into:
- Total Sales
- Total Profit
- Total Quantity
- Profit Percentage
- Monthly Sales Trend
- Category-wise Sales
- Sub-Category Analysis
- Payment Mode Analysis

---

## 🛠 Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Excel Dataset

---

## 📈 Dashboard Features
- KPI Cards
- Interactive Slicers
- Drill Through
- Tooltips
- Navigation Buttons
- Dynamic Charts
